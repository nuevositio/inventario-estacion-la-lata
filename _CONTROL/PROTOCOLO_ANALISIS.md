# PROTOCOLO DE ANÁLISIS DOCUMENTAL
## Fondo: Estación La Lata – Cardona

---

## FLUJO DE TRABAJO PARA CADA DOCUMENTO

### PASO 1: CARGA Y VERIFICACIÓN
- [ ] Documento cargado en la carpeta física correcta (ej: Carpeta01/)
- [ ] PDF legible y visible
- [ ] Número correlativo del documento asignado (DOC0001, DOC0002, etc.)

### PASO 2: ANÁLISIS DOCUMENTAL
1. **Observar físicamente el documento**
   - Formato (carta, oficio, etc.)
   - Tipo de soporte (papel, cartulina, etc.)
   - Legibilidad (clara, parcial, baja)
   - Integridad (completo, páginas faltantes)

2. **Identificar tipo documental**
   - Oficio
   - Carta
   - Acta
   - Expediente
   - Registro
   - Listado/Catálogo
   - Memorándum
   - Resolución/Decreto
   - Certificado
   - Factura/Recibo
   - Mapa/Plano
   - Fotografía
   - Otro: ___________

3. **Extraer información principal**
   - Fecha exacta o aproximada
   - Autor/Emisor
   - Destinatario
   - Institución vinculada
   - Lugar de referencia
   - Tema/Asunto

4. **Evaluar valor archivístico**
   - Valor administrativo (relevancia para gestión)
   - Valor histórico (relevancia para historia local)
   - Valor patrimonial (relevancia para patrimonio cultural)

### PASO 3: NOMENCLATURA TÉCNICA
**Formato obligatorio:**
```
LL_CarpetaXX_DOCXXXX.pdf
```

**Ejemplos:**
- LL_Carpeta01_DOC0001.pdf
- LL_Carpeta03_DOC0047.pdf

**Reglas:**
- LL = Estación La Lata
- CarpetaXX = número de carpeta física (con dos dígitos)
- DOCXXXX = número correlativo (con cuatro dígitos)
- No incluir fechas, temas ni descriptores

### PASO 4: DESCRIPCIÓN
- **Título:** Máximo 100 caracteres, descriptivo, sin interpretación
- **Descripción breve:** 2-5 líneas con contexto objetivo
- **Palabras clave:** 5-12 términos (nombres, lugares, instituciones, temas)

### PASO 5: VALIDACIÓN Y OBSERVACIONES
- Marcar si es duplicado
- Marcar si está incompleto
- Registrar cualquier dato incierto con [inferido]
- Señalar si requiere limpieza, restauración o digitalización adicional

## CRITERIOS DE DESCRIPCIÓN

### Redacción
- Máximo 5 líneas
- Incluir: nombres, fechas, instituciones, contexto
- Objetivo y sin interpretación subjetiva
- Usar términos archivísticos correctos

### Ejemplo
**"Documento:** Oficio dirigido por el Director de la Estación La Lata al Ayuntamiento de Cardona, fechado el 12 de marzo de 1982, solicitando autorización y fondos para realizar reparaciones en la canalización principal del sistema de distribución de agua. El documento incluye estimación de costos y cronograma de obras."

## PALABRAS CLAVE

### Categorías a incluir
1. **Nombres propios:** Personas, instituciones
2. **Lugares:** Localidades, geografía
3. **Temas:** Asuntos centrales
4. **Procesos:** Actividades, acciones
5. **Eventos históricos:** Momentos clave

### Ejemplo
```
agua, infraestructura, reparación, Estación La Lata, 
Cardona, Ayuntamiento, distribución, autorización, 1982
```

---

## MARCAS ESPECIALES

- **[inferido]:** Cuando la información se deduce pero no está explícita
- **[dudoso]:** Cuando hay incertidumbre
- **[incompleto]:** Cuando faltan páginas o está cortado
- **[ilegible]:** Cuando no se puede leer
- **DUPLICADO:** Cuando hay otro documento idéntico
- **PATRIMONIO:** Cuando tiene valor histórico o cultural excepcional
